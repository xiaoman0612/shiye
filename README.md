# 拾页 · 小说推荐工具

> 🌐 **在线访问**：https://xiaoman0612.github.io/shiye/
> 📦 仓库：https://github.com/xiaoman0612/shiye
> 🔁 镜像站：https://hjb08432.github.io/shiye/

输入喜欢的类型、氛围或一句模糊的感觉，从 **网络小说、现实向文学、类型出版** 三条轨道里，找到下一本书；找不到的时候，可以让大模型当场再翻一遍。

这是一个纯前端、离线可用的单页工具。无需安装依赖，直接用浏览器打开 `index.html` 即可；线上版本由 GitHub Pages 托管。

## 能做什么

- **自然语言选书**：支持“想看点轻松的悬疑，最好短一点，不要 BE”这类描述，也支持直接输入书名或作者。
- **多条件筛选**：书库类型、阅读状态、篇幅、排序；书目覆盖网络小说、现实向文学与类型出版。
- **有内容的推荐**：每个结果给出匹配度、命中偏好，以及编辑评分、分项评分、书评、优点、注意点和读者口碑关键词。
- **AI 实时找书**：接上你自己的大模型后，书库没收录的书也能现场推荐出来，并标注确认度、附豆瓣核对入口。
- **正版资源入口**：每本书提供官方阅读平台、微信读书、豆瓣读书、京东图书或 WorldCat 馆藏检索等入口。
- **书架与夜间模式**：收藏保存在浏览器本地；支持日间 / 夜间阅读主题。

## 使用

1. 打开 https://hjb08432.github.io/shiye/ （或本地 `index.html`）。
2. 输入类型或从快捷标签开始，点击「替我找书」。
3. 打开搜索面板里的 **AI 实时找书** 开关，第一次会提示填一个大模型接口（见下节），之后每次搜索模型都会现场补一轮。
4. 点开任意一本书，查看完整书评、资源与相似作品。
5. 点书签把书放进「书架」。

所有资源链接都跳转到平台站内搜索或图书页面。连载状态、版权与库存会变化，请以平台为准。

## AI 实时找书

书库是 43 本人工策展的书，AI 负责补上策展之外的部分。**不需要后端**：浏览器直接调用你填的 OpenAI 兼容接口。

**怎么开**

1. 点搜索面板右侧的「设置」（或导航栏的「AI 找书」）。
2. 选服务商，或选「自定义」手填 Base URL；模型名可下拉选、也可自己写。
3. 填入 API Key，点「先测一下连接」确认通，再「保存并启用」。

**预设服务商**：DeepSeek、Moonshot 月之暗面、智谱 GLM、通义千问（DashScope 兼容模式）、SiliconFlow、火山方舟、OpenAI、自定义。任何兼容 `POST {baseUrl}/chat/completions` 的服务都能用。

**隐私与安全**

- Key 只写进**这台设备**的 `localStorage`，不经过拾页的服务器（本站没有服务器），也不会出现在分享出去的链接里。
- 想彻底清掉，在设置弹窗里点「清除 Key 与历史」，或用浏览器的站点数据清理。
- 公开电脑上请勿保存 Key。若站点要求，可优先使用限额度、可随时吊销的 Key。

**结果怎么读**

- AI 结果和编辑精选**分区展示**，卡片带 `模型生成` 标记与 **确认度**（高 / 中 / 低）。
- 模型会编造书名——这不是 bug，是概率模型的本性。每张卡都给了「豆瓣核对」按钮，**入库前请先核对书名与作者**。
- AI 推荐的书可以存进书架、可以打开详情，但它没有编辑评分，详情页会明确写「未经拾页核实」。
- 换一批（`force`）会跳过本地缓存重新问一次；同一句查询重复搜索会复用上一条结果以省额度。

**排查**

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「接口返回 401」 | Key 错、过期或没有该模型权限 | 重新粘贴 Key，或换一个模型名 |
| 提示「连不上接口 / CORS」 | 用 `file://` 直接打开，或该服务不允许浏览器直连 | 用 http 本地服务器打开；或换支持 CORS 的兼容接口 |
| 提示「额度不足」 | 账户余额用尽 | 到服务商后台充值 |
| 一直停在「模型正在写书单…」 | 输出过长或网络慢 | 点「停止」，把需求写短一点再试 |

## 文件结构

```text

```

## 部署

本站托管在 **GitHub Pages**（分支 `main`、根目录 `/`、legacy 构建），没有构建步骤，改动直接生效。

```powershell
git add -A
git commit -m "feat: AI 实时找书 + UI 改版"
git push origin main
```

也可以沿用仓库外那套 `deploy/publish.ps1`（校验身份 → 提交全部文件 → 等 Pages 构建完成 → 回显线上状态）：

```powershell
$env:GH_TOKEN = "你的 PAT"
./deploy/publish.ps1
```

推上去之后 Pages 通常 30–60 秒内重建完成。本地预览：任意静态服务器指向仓库根目录即可，例如 `python -m http.server 5188` 或 `npx serve .`。

## 关于内容

- 书目、评分、长评、优点 / 注意点与口碑关键词均为编辑策展内容，**不是豆瓣或任何平台的官方评分**。
- AI 推荐由模型实时生成，**未经编辑核实**，仅作线索。
- 不抓取、不转载第三方书评，不提供盗版下载或资源搬运。
- 封面为根据每本书配色生成的文字版式，不使用受版权保护的封面图片。

书单与资源入口最后校对：2026 年 11 月。
